# MR Gesture Icons｜混合實境手勢圖示

兩組研究手勢的對應圖片，供簡報與紙本文件使用。SVG 手型仍在確認中。

| 資料夾 | 組別 |
|---|---|
| `domestic/` | 本國組，原九宮格 |
| `international/` | 非本國組，原黃色表格 |

## 指令對照

| 編號 | 指令／檔名 | 本國組 | 非本國組 |
|---|---|---|---|
| 01 | 開啟 `open` | 比讚 | 食指向前推動 |
| 02 | 確認 `confirm` | OK | 比讚 |
| 03 | 上一步 `previous` | 整隻手向左移動 | 食指指向左 |
| 04 | 下一步 `next` | 整隻手向右移動 | 食指指向右 |
| 05 | 放大 `zoom-in` | 手掌展開 | 拇指與食指展開 |
| 06 | 縮小 `zoom-out` | 手掌收合 | 拇指與食指捏合 |
| 07 | 重播 `reload` | 手掌順時針畫圈 | 食指順時針畫圈 |
| 08 | 截圖 `capture` | 沿用研究者指定的截圖手型 | 拇指與食指各彎一個指節 |
| 09 | 關閉 `close` | 握拳 | 握拳 |

## 命名原則

格式：`兩位指令編號-指令名稱-圖片編號-用途.svg`。兩組使用一致的指令順序。

| 後綴 | 用途 |
|---|---|
| `-0-complete.svg` | 完整表意；動態手勢合併前後姿態與箭頭 |
| `-1-start.svg` | 動態手勢的起始姿態 |
| `-2-end.svg` | 動態手勢的結束姿態 |

例如 `08-capture-0-complete.svg`。篩選 `-complete.svg` 可取得兩組共 18 張完整圖；連同動態拆分版本，共 40 張 SVG。

SVG 確認後另存同名 PNG，直接放在所屬組別資料夾。修改直接更新原圖，預覽與討論留在對話中。

## 製作方式

謝祥紫提供手勢定義、簡報及照片，並確認圖示。OpenAI Codex（GPT-6.1 Sol）協助編寫 SVG 向量路徑；以原圖的手型為基準，照片輔助辨識骨架與指節，統一黑色線條及 320 × 320 畫布。動態圖使用灰色起始姿態、黑色結束姿態與方向箭頭。人體結構與動作以研究者確認為準。
